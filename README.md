# Avito Reviewer Service

Тестовое задание Авито (осень 2025). Сервис назначения ревьюеров на Pull Request.
https://github.com/avito-tech/tech-internship/blob/main/Tech%20Internships/Backend/Backend-trainee-assignment-autumn-2025/Backend-trainee-assignment-autumn-2025.md

## Cделано:
- Создание Pull Request.
- Назначение до 2 ревьюеров из команды автора.
- Просмотр своих PR.
- Выгрузка данных для ML-инженера.

## Чего нет и почему:
- Управление командами (считаем, что команды уже существуют).
- База данных (хранение в оперативной памяти).

## Как запустить:
1. Скачайте проект и распакуйте (или склонируйте через git).
2. Откройте терминал в папке с проектом.
3. Перейдите в папку с исходным кодом: `cd AvitoReviewerService` (если вы скачали ZIP, папка может называться с припиской `-master`).
4. Запустите проект командой: `dotnet run`
5. Откройте `http://localhost:5216/swagger`

## Смежная роль (ML-инженер):
Добавлен эндпоинт `/api/ml/export`, который выгружает историю PR. Это нужно для обучения модели, которая в будущем будет сама предлагать лучшего ревьюера.

## Как проверяли:
1. Запускали проект локально командой `dotnet run`.
2. Открывали Swagger UI по адресу `http://localhost:5216/swagger`.
3. Отправляли POST-запрос на создание PR (возвращался код 200 и JSON с данными).
4. Отправляли POST-запрос на назначение ревьюеров (проверяли, что назначаются только члены команды, а автор исключен).
5. Проверяли GET-запросы на получение списка PR и выгрузку для ML.
6. Запуск на чистой машине был подтвержден однокурсником.
